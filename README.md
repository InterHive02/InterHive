# InterHive

## From Intern to Industry

InterHive is a comprehensive industry-readiness and talent-connect platform that transforms students into evaluated, project-experienced, industry-ready professionals.

## 🚀 Quick Start

### Prerequisites
- Node.js 18+
- Yarn 1.22+
- Docker (optional)

### Installation
```bash
# Clone repository
git clone https://github.com/interhive/interhive.git
cd interhive

# Install dependencies
yarn install

# Start development servers
yarn dev
